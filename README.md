# SQL Data Analysis Portfolio

SQL analysis of logistics and order data, built by **Remy Rukundo**.

I've worked in logistics data and B2B fulfilment, so these projects use realistic order and shipment scenarios to answer real business questions.

## Project 1: Order & Delivery Performance

**Business questions answered:**
- How many orders are in each status (delivered, pending, cancelled)?
- How long does delivery take per warehouse?
- How many orders ship per month?
- Which shipments were late?

**Skills shown:** SELECT, GROUP BY, aggregate functions, date calculations, filtering with WHERE and HAVING, CASE statements.

**Files:**
- `queries/01_logistics_analysis.sql`: sample data and all queries
